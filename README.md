# XeSS 离线视频工具箱 / XeSS Offline Video Toolbox

Windows 离线视频超分与 2× 插帧工具。解压即用，内置图形界面及运行环境，不需要安装 Python、ComfyUI、OBS 或 .NET。

## 下载与启动

1. 打开 [最新版本](https://github.com/gggz114514-oss/XeSS-Offline-Video-Toolbox/releases/latest)，下载 **XeSS-Offline-Windows-x64-v1.0.0.zip**，不要下载 GitHub 自动生成的 Source code。
2. 完整解压到有足够空间、可写的本地文件夹，双击 **XeSS-Offline.exe**。支持中文、空格路径和任意盘符。
3. 选择原视频、处理模式、算法路线、倍率和编码器，点击“开始处理”。原片不会被覆盖。
4. 等待校验完成，点击“播放成片”。遇到问题，查看“运行日志”或点击“环境检查”。

默认输出在 `output`，任务与缓存放在软件目录的 `data`。不要直接在压缩包里运行，不要在处理时清理缓存。更新时解压到新文件夹即可，旧版和原视频可以保留。

## 选择路线

| 路线 | 定位 | 超分 / 2×插帧 / 超分后插帧 |
| --- | --- | --- |
| GPU Block | 默认快速路线 | 支持 |
| CPU DIS | 传统光流，稳定优先 | 支持 |
| Intel 视频接口 | Intel 官方 AI 视频处理 | 支持 |
| GPU DIS | 实验项，不保证画质 | 支持 |
| AMD 光流 | 实验项，指光流算法名称 | 支持 |

- 超分倍率：1.33×、1.5×、2×或自定义 1–4×；预检会显示按引擎要求对齐后的实际尺寸。
- 锐化、五帧融合、抗竖纹按路线和模式显示；Intel 视频接口不提供这些附加效果。GPU 路线超分和一条龙支持三项效果；CPU DIS 五帧融合限独立超分。
- 五帧融合适合静态、慢运动，快速运动可能重影。抗竖纹按需开启，可能增加耗时。超分再插帧建议只在最后锐化一次。
- 独立插帧只有锐化，不显示无效的五帧融合或抗竖纹选项。
- 支持原音轨保留。XeFG 输出 `2N−1` 帧，Intel 视频接口输出 `2N` 帧；离线不提供 3×/4×，不通过复制帧伪装多倍生成。

## 编码器

默认 H.264 GPU；还可选择 H.265 GPU、H.264 CPU、H.265 CPU、FFV1 无损 MKV。GPU 编码使用 Intel QSV；软件编码不要求使用 QSV 编码器，但不代表整个处理链已脱离 Intel 平台。软件编码会将最终画面回读到系统内存。

FFV1 的“无损”指最终编码阶段，不表示超分或插帧不修改画面；文件通常明显大于 H.264/H.265。建议普通观看使用 H.264，后续编辑与严谨对比使用 FFV1。

## 已验证环境与限制

当前便携版在 **Windows 11 + Intel Arc B580** 实测。显卡驱动需要用户正确安装。A770、AMD、NVIDIA 显卡及 Windows 10 未在此包完成验证；“AMD 光流”不是 AMD 显卡全链支持承诺。

GPU 路线主要支持 8-bit SDR H.264/HEVC 4:2:0、固定帧率视频；HDR、全范围、旋转元数据或异常时间戳等不支持的输入会明确拒绝，不会静默降低画质。复杂素材可尝试 CPU DIS，仍以预检结果为准。

便携包内置 Python、OpenVINO、模型、FFmpeg/ffprobe、自包含桌面运行库和固定版 WebView2；没有实时捕获、OBS/WGC 前端或 ComfyUI 节点。联网不是本地处理的必要条件。

验证范围见 [验收摘要](VALIDATION.md)。首版已覆盖多路线短片、1200 帧连续处理及取消/关窗；不宣称电影时长、所有驱动、所有显卡全覆盖。
